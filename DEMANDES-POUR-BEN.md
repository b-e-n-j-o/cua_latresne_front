# Demandes pour Ben

Demandes de Christophe qui sortent du périmètre de la landing (application,
authentification, animations, nouvelles pages, dépendances…).
Claude ajoute une entrée à chaque demande hors périmètre. Ben les traite et
les marque comme faites.

Format :

```
## AAAA-MM-JJ — <titre court>
- Demande : <ce que Christophe veut, avec ses mots>
- Pourquoi c'est pour Ben : <fichier/zone concernée>
- Statut : à faire
```
